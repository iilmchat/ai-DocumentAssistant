# Журнал изменений (Changelog)

## [1.0.0] - 2026-11-17
### Добавлено
- Базовая архитектура приложения: FastAPI + React + PostgreSQL (`pgvector`) + Celery + Redis.
- Загрузка и парсинг форматов PDF, DOCX, TXT.
- Фоновый пайплайн векторизации чанков и генерации краткого конспекта.
- Интерактивный RAG-чат с отображением релевантных фрагментов текста.
- Конфигурация Docker Compose и Nginx Reverse Proxy.
