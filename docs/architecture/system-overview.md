# Обзор архитектуры системы

## Компоненты системы
Приложение построено по микросервисной архитектуре в Docker-контейнерах:

1. **Frontend (`ai_frontend`):**
   - SPA на React + TypeScript, собранное через Vite.
   - Раздается веб-сервером **Nginx**, который также выступает обратным прокси (Reverse Proxy): все запросы на `/api/*` перенаправляются в контейнер `backend:8000`.
2. **Backend (`ai_backend`):**
   - Асинхронный REST API на **FastAPI**.
   - Отвечает за прием файлов, управление метаданными в PostgreSQL, постановку задач в Redis и выполнение RAG-запросов.
3. **Celery Worker (`ai_celery_worker`):**
   - Фоновый обработчик задач.
   - Читает загруженные файлы из общего тома (`shared_storage`), извлекает текст, разбивает на чанки, вычисляет эмбеддинги и формирует конспект.
4. **PostgreSQL + pgvector (`ai_postgres`):**
   - Реляционная БД для хранения информации о документах и векторное хранилище для поиска по косинусному сходству.
5. **Redis (`ai_redis`):**
   - Брокер сообщений для очереди задач Celery.

## Схема потоков данных
```
[Browser] ---> [Nginx :80] ---> /api/* ---> [FastAPI Backend :8000]
                                                   |          |
                                         (SQL)     v          v (Task)
                                           [PostgreSQL]    [Redis]
                                           (pgvector)         |
                                                   ^          v
                                                   +-- [Celery Worker] ---> [LLM / Embeddings API]
```
