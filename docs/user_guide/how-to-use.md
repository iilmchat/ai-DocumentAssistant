# Руководство пользователя («AI Конспект»)

## 1. Загрузка документа
1. Нажмите кнопку **«Загрузить документ»** в левой боковой панели.
2. Выберите файл с компьютера в формате **PDF**, **DOCX** или **TXT**.
3. Дождитесь завершения обработки (статус документа изменится на готовый, и файл появится в списке слева).

## 2. Просмотр умного конспекта
- Выберите нужный документ в левом меню.
- На основной панели автоматически откроется вкладка с **структурированным конспектом**, содержащим главные тезисы, выводы и ключевые факты документа.

## 3. Работа с RAG-чатом
1. Переключитесь на вкладку **«Чат по документу»** (или используйте поле ввода вопроса внизу экрана).
2. Задайте вопрос на естественном языке (например: *«Перечисли основные требования из раздела 3»*).
3. Система найдет точные фрагменты в тексте и сформирует ответ с указанием цитат-источников, на основе которых он был составлен.
