# Перевод документов (T6)

## Как пользоваться

1. Загрузите документ и дождитесь статуса «Готов».
2. Откройте вкладку **«Перевести»**.
3. Выберите целевой язык (RU / EN / DE / FR / ES) и нажмите «Перевести документ».
4. Следите за прогрессом — перевод выполняется в отдельной очереди, оригинал не меняется.
5. После завершения:
   - вкладка «Страницы» показывает переключатель «Оригинал / Перевод / RU / EN»;
   - RAG-чат ищет по обоим языкам и возвращает цитаты с страницами;
   - на вкладке «Перевести» доступен экспорт MD / DOCX / PDF.

## Глоссарий терминов

Добавьте пары «термин → перевод» на вкладке «Перевести», чтобы модель не меняла
юридические или фирменные термины. После изменения глоссария кэш переводов инвалидируется.

## Что защищено автоматически

Числа, суммы, даты, ИНН и коды вида `A12-34` подменяются плейсхолдерами перед запросом
к модели и восстанавливаются после перевода — они не должны изменяться.

## Важно

Перевод выполняется моделью (машинный перевод). Для юридических и медицинских документов
требуется проверка человеком; экспорт помечается `[MT]`, а в UI есть предупреждение.
Стоимость перевода отражается в `GET /api/v1/auth/usage` (operation=`translate`).

## Ограничения

- Поддерживаемые языки задаются `SUPPORTED_LANGUAGES` (по умолчанию ru,en,de,fr,es).
- Если язык документа совпадает с целевым, перевод не запускается.
- Повторная загрузка того же файла не создаёт дубликат (идемпотентность по SHA-256).
