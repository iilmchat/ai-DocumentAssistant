# Безопасность и управление секретами

1. **Хранение API-ключей:**
   - Ключи (`OPENAI_API_KEY` и др.) передаются исключительно через переменные окружения (`.env`) и никогда не должны попадать в систему контроля версий Git (убедитесь, что `.env` добавлен в `.gitignore`).
2. **Валидация загружаемых файлов:**
   - Бэкенд проверяет расширение и размер файла перед сохранением на диск.
   - Имена файлов при сохранении в `shared_storage` санитизируются (используются UUID) для предотвращения атак типа Path Traversal.
3. **Изоляция сервисов:**
   - PostgreSQL и Redis доступны внутри изолированной сети Docker (`ai-documentassistant_default`). В продакшене рекомендуется закрыть проброс портов `5432` и `6379` наружу.
